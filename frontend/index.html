Manual de Usuario - Antigravity WA-ERP Suite

Guía oficial de uso para el panel en la nube de WhatsApp Business Cloud API & ERP/CRM Integration

1. Bandeja Multiagente

  • Filtros por Estado: Alterna entre Todos, En Proceso (asesor humano) e IA Bot (respuestas automáticas).
  • Buscador: Escribe nombre, teléfono o tag en la barra superior.
  • Acciones Rápidas: Usa los botones 📝 Nota Interna, 📦 Catálogo ERP y 🧾 Factura PDF.
  • Transferencia: Reasigna la conversación usando el botón Transferir Chat.

2. Embudo CRM Kanban

  • Visualiza el estado de tus tratos desde el primer contacto en WhatsApp.
  • Etapas Especiales de Despacho:
    • Factura y Despacho en Sucursal: Para retiros presenciales en caja.
    • Factura y Despacho a Domicilio: Captura la distancia en Kilómetros (KM), chofer asignado y tiempo estimado de llegada (ETA) enviando actualización automática por WhatsApp.
  • Muestra el valor estimado ($) y datos del cliente en cada tarjeta con selector directo.

3. Consola ERP y Ventas

  • Emisión de Documentos: Haz clic en Crear Cotización / Pedido.
  • Selecciona entre Cotización (COT), Pedido (PED) o Factura (FAC).
  • Agrega productos del inventario y el sistema calculará subtotal, IVA 13% y total.
  • Al emitir, se envía automáticamente el enlace PDF al WhatsApp del cliente.

4. Motor de Reglas No-Code

  • Detecta palabras clave en mensajes entrantes (ej. PRECIO, FACTURA).
  • Ejecuta respuestas automáticas conectadas directamente con el stock o facturación ERP.

5. Dashboard Ejecutivo

  • Métricas en tiempo real: Mensajes totales, Leads WA, Ventas originadas y SLA de respuesta.
  • Tabla de rendimiento por vendedor con estado online y monto de ventas creadas.

6. Meta Cloud & Auditoría

  • Verificación de tokens y webhooks de Meta WhatsApp Cloud API v19.0.
  • Bitácora de Auditoría inalterable que registra todas las operaciones por fecha, usuario y recurso.
